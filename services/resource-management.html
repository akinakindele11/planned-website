Resource loading and levelling

A programme that matches the gangs, plant and specialists you actually have.

Talk to us

Many programmes are logically sound and still cannot be built, because they assume the same gang, the same crane or the same specialist is in three places at once. The problem shows up on site, as slippage nobody can trace back to the programme.

Planned loads and levels programmes in Primavera P6 so the dates reflect the resources you actually have. We work on single projects and across portfolios where several jobs draw on the same people and plant.

When it matters most

  • Labour-constrained work, where a limited number of gangs or specialist teams move from one area to the next.
  • Work in possessions, outages or access windows, where resources have to be available exactly when the window opens.
  • Major plant, such as cranes, piling rigs or tunnelling equipment, shared across the job.
  • Portfolios, where one team or framework supplier serves several projects at once.

What we do

  • Load resources from the method and the gang sizes, so histograms show real demand rather than a guess.
  • Compare demand against availability and show where and when the programme is over-committed.
  • Level the programme using agreed priorities, keeping the logic intact and documenting every date that moves.
  • Where durations should depend on resources, set them up that way, so the programme responds when the plan changes.
  • For portfolios, build the shared resource view across projects, so conflicts are visible before they reach site.

A word of caution on levelling

Levelling can quietly change the critical path and push float around. We never level silently: you get a note of what moved, why, and what the levelled critical path now is, so the programme stays defensible if it is ever examined.

Who does the work

A named lead from our planning team does the work, and a senior planner reviews the result before issue. See how we work.

Common Questions

Can you resource load a programme that is already running?

Yes. We load from the current position, agree the resource rules with your team and level from the next update.

Will levelling change our completion date?

It can, if the programme assumed resources you do not have. We show the effect and the options, such as extra resource or a different sequence, before anything is adopted.

Do you level across several projects?

Yes. We set up a shared resource view so the demand from each project is visible against the same availability.

Which tools do you use?

Primavera P6 or Oracle Primavera Cloud. We can host the programme in our own licensed P6.

Programme that cannot be resourced?

Send us the programme and the resources you have. We reply within one working day.
